# SalesPilot AI — MVP

Локальное SaaS-приложение для демонстрации AI Sales Assistant малого бизнеса.

## Запуск

В папке проекта выполните:

```powershell
& 'C:\Users\User\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' server.js
```

Затем откройте `http://localhost:5173`.

Для быстрого ознакомления выберите «Войти в демо». Все действия сохраняются в `localStorage` браузера; очистка данных сайта сбросит демо-данные.

## Что работает

- регистрация, вход и пошаговый onboarding;
- добавление, редактирование и CSV-импорт товаров;
- база данных бизнеса и demo AI, который отвечает по каталогу без выдумывания данных;
- создание и ведение диалогов, передача менеджеру;
- изменение статусов лидов и заказов, создание заказа;
- dashboard, аналитика, настройки AI, тарифы и честно обозначенные mock-интеграции.

Это автономный MVP: постоянное хранение устроено в браузере, а не в внешней БД. Файлы `server.js`, `index.html`, `styles.css` и `app.js` находятся в корне проекта.
